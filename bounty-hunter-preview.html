Bounty Hunter

A year-round clan activity run by the Myriad Events Bot. Every Monday a new boss bounty goes up. Members post their drop, an admin approves it, and points are paid out. Points can be spent in a shop and also count toward monthly and all-time leaderboards.

Every bounty comes with a secret code word that only appears when the bounty is posted. It must be visible in each screenshot, so only drops from that week count.

Runs all the time, including during bingo and drop races. Bounty Hunter commands all start with /bh so they never mix with event commands.

The weekly cycle

How a week works

All times are UTC (game time). The posting hour changes every week so no timezone always gets the head start.

MON · random hour New bounty posted

The bot picks a random hour on Monday (00:00–23:00 UTC), posts the new boss with this week's code word and pins it. Last week's bounty closes.

MON → THU Race for first claim

The first player to get the drop approved gets the big reward. Everyone after that gets the smaller one.

+72 HOURS Multiplier kicks in

If nobody has claimed it 3 days (72 hours) after posting, the first claim becomes worth ×2.

UNTIL NEXT MON Everyone can still claim

One claim per player. The pinned post updates live as people claim, until the next bounty replaces it.

Points system

Who gets what

The numbers below are placeholders. Admins set them per bounty in the Google Sheet, so a harder boss can pay more.

10First claim

The first player whose claim is approved.

5Every later claim

Everyone else who completes the bounty that week. One claim per player.

×2Unclaimed for 72 hours

Doubles the first claim only (10 → 20). Later claims stay at 5.

Bounties with several parts

A bounty can need more than one drop. Players can post each part as they get it, and the bot tracks their progress. The bounty counts as claimed when all parts are approved, so "first claim" means the first player to finish every part.

#bounty-submissions

Submitting and approving

Same habit as the bingo and drop race: post a screenshot with the item name, then an admin reacts ✅. The bot only watches this channel for bounties, so event posts and bounty posts never get mixed up. Each approval is written to its own Bounty Hunter Google Sheet.

1 · Type the code word

When the drop appears, type this week's code word in your in-game chat (for example clan chat) so it is on screen.

2 · Screenshot drop + code word

One screenshot that shows the drop and the code word together. A screenshot from before the bounty was posted can't have it.

3 · Admin checks, then ✅

The bot can't read images, so the admin checks the code word before reacting. Missing code word = no ✅.

The bot picks a secret code word when it posts the bounty. Admins can also choose their own in the sheet beforehand. Each week has a different one.

Your input

Questions for the admin team

Answers to these decide how the bot is built. Anything not answered stays as shown above.

  1. Point valuesIs 10 for the first claim and 5 for later claims right? Should harder bosses pay more (set per bounty)?
  2. Multi-part bountiesPoints only when every part is done (as shown), or a few points per part as well?
  3. MultiplierOnly ×2 after 72 hours, or should it keep growing (for example ×3 after 5 days)? Any multiplier for later claims?
  4. Late claimsCan someone still claim last week's bounty after the new one is posted (for example within 24 hours), or does it close right away?
  5. LeaderboardsIs "this month" and "all time" enough, or do we also want "this year"? Should the monthly winner get a prize?
  6. ShopWhich items, what prices, limited stock or not, and which admins deliver them?
  7. Who picks the bossesAdmins fill a list in the sheet in advance, or the bot picks at random from a pool?
  8. Code wordIs "typed in your in-game chat" the right rule, or should it be somewhere specific (for example clan chat only)? Should the bot pick it, or do admins want to choose each week's word?
  9. VisibilityShould partial progress be public on the pinned post ("2 hunters have 1 of 2 parts") or private to each player?
